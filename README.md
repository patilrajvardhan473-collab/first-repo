## CommonGround — local service directory

A responsive service directory prototype with keyword search, category filters, clickable directions and phone links, and a suggestion form.

The Springfield listings and phone numbers are fictional demo data, not verified referrals. Replace them with current, verified information before people rely on the directory. Suggestions submitted through the demo form stay in the visitor's browser and are not sent to an administrator.

The site files are in the repository root: `index.html`, `styles.css`, and `app.js`.
